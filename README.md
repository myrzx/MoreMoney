# 💰 MoreMoney - 今天你赚了多少钱？

> 右下角薪资实时可视化工具，挖矿风格，支持系统托盘

## 功能

- **实时薪资滚动** — 按工作时长（默认 9:00–17:30）计算今日已赚金额
- **等价物换算** — 金额保密，切换为奶茶/手办/显卡等实物显示
- **挖矿风动画** — 荧光发光数字、粒子漂浮、扫描线效果
- **系统托盘** — 关闭即最小化到托盘，点击托盘显示/隐藏
- **Always-on-top** — 浮动在右下角，不受其他窗口遮挡
- **工作日识别** — 周末自动停止计薪
- **自定义配置** — 月薪、工作时间、等价物均可配置

## 使用

```bash
npm start
```

- 点击等价物图标 🧋 可切换不同等价物
- 点击 ⚙ 打开设置面板
- 点击 ━ 最小化到托盘
- 右键托盘图标 → 退出

## 配置

首次启动自动生成配置文件 `config.json`（位于 `%APPDATA%/more-money/`），也可在设置面板中修改：

- `monthlySalary` — 月薪（元）
- `workStart` / `workEnd` — 工作起止时间
- `equivalents` — 等价物列表（名称、图标、单价）
- `selectedEquivalent` — 当前选中的等价物索引

## 打包

```bash
npm run build
```

生成的可执行文件在 `dist/` 目录。

## 薪资计算逻辑

```
月薪 ÷ 21.75（月均工作日）÷ 8（小时）÷ 3600（秒）= 秒薪
今日已赚 = 秒薪 × 已工作秒数（仅计算 9:00–17:30 期间）
```

启动时自动根据当前时间计算该时段内已赚金额，不从零开始。
